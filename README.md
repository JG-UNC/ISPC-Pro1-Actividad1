# ISPC-Pro1-Actividad1

Actividad 1 del **Proyecto Integrador I** (ISPC, Tecnicatura en Ciencia de Datos e IA).

## Contenido

- `config/`: configuración del proyecto Django.
- `api/`: aplicación `api` con los modelos y vistas de la actividad.
- `db.sqlite3`: base de datos SQLite de desarrollo.
- `manage.py`: utilidad de administración de Django.

## Tecnologías

Python, Django, SQLite.

## Ejecución local

```bash
pip install django
python manage.py migrate
python manage.py runserver
```
